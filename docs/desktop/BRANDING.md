# Desktop branding and identifiers

Reference for the product name, the stable bundle identifiers, and what the app may claim. Harness Desktop is an unofficial desktop client: nothing in the product implies DeepSeek endorsement.

## Product name

The application is named Harness Desktop. Onboarding, About, and the error surfaces state that the app is an unofficial client based on DeepSeek Harness; the About window repeats the non-affiliation note.

## Stable identifiers

These values ship to users and must not change casually:

- Application name: Harness Desktop
- Bundle identifier: com.deepseek.harness.desktop (reverse-DNS, stable)
- Executable: harness-desktop (inside Contents/MacOS)
- Keychain service: com.deepseek.harness.desktop
- Log directory: <Application Support>/com.deepseek.harness.desktop/logs
- Preferences file: <Application Support>/com.deepseek.harness.desktop/prefs.json
- DMG name: Harness-Desktop-<version>-macOS-arm64.dmg

## Artwork

The app icon is original geometry generated by scripts/desktop-icon.mjs (a gradient squircle with a harness mark). No DeepSeek artwork is bundled; the shell's in-product branding comes from the upstream client packages unchanged.
