# Roadmap

No dates are promised.

## 0.1 — macOS public preview

Signed and notarized DMG on GitHub Releases, first-run onboarding,
sessions, streaming, tool calls, approvals and questions, attachments, and
the English/Italian surfaces. Shipped as a Pre-release.

Terminal, changes/diff view, file explorer, Git integration, plan and
subagent surfaces, and model/permission refinements.

The Tauri updater, Intel and universal macOS builds, and further upstream
rebase automation.

## Future

MCP management, plugin management, and any Harness capabilities that
upstream stabilizes.
